## 📊 Round Readiness Self-Assessment

Before appearing for an on-campus or off-campus technical drive, evaluate yourself across these 5 gates (Target: $\ge 4/5$ in each):

1. **Frontend Architecture & React Internals**: [ /5 ]
   - Can explain Fiber tree phases, stale closures in hooks, reconciliation keys, and RSC boundaries.
2. **TypeScript & Type System Rigor**: [ /5 ]
   - Can write generic constraints, conditional types, discriminated unions, and strict TS without `any`.
3. **Backend Engineering & Node Runtime**: [ /5 ]
   - Can trace Libuv event loop phases, build layered Express APIs, and prevent unhandled promise crashes.
4. **Database Mechanics & Query Optimization**: [ /5 ]
   - Can write complex joins, window functions, and CTEs in PostgreSQL, and diagnose unindexed queries via `EXPLAIN`.
5. **System Design & High-Level Scalability**: [ /5 ]
   - Can structure functional/non-functional requirements, estimate traffic/storage, and design scalable caching & messaging architectures.
